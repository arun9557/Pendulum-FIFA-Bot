# AI Soccer Arena - Team Pendulum Quickstart Guide

This guide provides instructions on how to use, test, evaluate, and package the **Pendulum** bot for **Conv-Cup '26: FIFA of Bots** (CyberLabs, IIT ISM Dhanbad).

---

## 2. How to Run and Use

All commands are executed from the `participants` directory in PowerShell:

```powershell
cd C:\Users\USER\Downloads\Mlfootball_env\participants
```

### A. Run Automated Tests
Verify that the simulation environment and policies run without errors:
```powershell
python -m unittest discover -s tests -v
```

### B. Watch Live Match in Browser Viewer
Start an interactive visual match where **Pendulum** plays against **Balanced United RL Reference**:
```powershell
python live_viewer.py
```
- Open `http://127.0.0.1:PORT/` in your browser (opens automatically).
- Controls: pause, step forward, toggle commentary, and change playback speed.
- Press `Ctrl+C` in the terminal to stop the viewer.

### C. Run Headless Practice Match
Run a fast match directly in the terminal:
```powershell
python run_match.py --submission my_team/submission.json
```

### D. Validate on Official Tournament Seeds (20 Matches)
Test **Pendulum** across 10 tournament seeds playing both as Player 1 (attacking UP) and Player 2 (attacking DOWN):
```powershell
python validate_submission.py --submission my_team/submission.json --matches-per-side 10 --seed 7000
```

### E. Package Submission for Unstop
Package your team into a clean ZIP archive ready for upload to Unstop:
```powershell
python package_submission.py my_team dist/Pendulum.zip
```

### F. Verify Submission Archive
Check that the ZIP strictly complies with Unstop constraints (file size, dependencies, forbidden imports):
```powershell
python check_submission.py dist/Pendulum.zip --report dist/Pendulum-report.json
```
